# DriveWise — Car Dealership Review Application

A full-stack car dealership review application developed as part of the IBM Full Stack Software Developer Capstone Project.

## Project Overview

DriveWise allows users to browse car dealerships, filter dealerships by state, view dealer details, and submit customer reviews.

## Technologies

- Django and Django REST Framework
- React.js
- Node.js and Express.js
- MongoDB and SQLite
- Docker and Kubernetes
- GitHub Actions for CI/CD

## Main Features

- User registration and authentication
- Dealership listings and search
- Dealership filtering by state
- Customer reviews and ratings
- Sentiment analysis
- Django administration panel
